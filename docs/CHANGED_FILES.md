# Changed files

Compared with the unmodified LocalSend source supplied in `localsend-main.zip`.
The complete modified project is delivered, not only these changed files.

- UI: blue/white themes, native typography, home tools, Send header and introduction.
- Branding: translated app-name strings, master artwork, platform icon/splash resources and visible app labels.
- Features: QuickPair, separately encrypted QuickVault with optional native biometrics, sent-history persistence/search/resend and per-recipient cancellation.
- Remote sharing: Flutter HTTPS sender, opt-in UI, Python bounded-memory relay, browser receiver, tests and deployment configuration.
- Reliability/security: Linux interface monitoring without NetworkManager, privacy of default debug state logs, serialized sent-history writes, and cross-platform native test-library selection.
- Platform identity: fork bundle/application/installer IDs, signing-team placeholders and biometric configuration; internal protocol/channel/executable names retained.
- Documentation: build instructions, architecture, validation results, upstream README and retained license attribution.
